A house in the game today is about 40 triangles (a box and a roof), with its windows painted on. The old town has roughly 1,100 houses, so the close-up version can only be used for the few dozen nearest the player. The light version is the one to use everywhere else, and even it is a real cost on a phone: it should be measured before it goes in across a whole district.

A pedestrian today is about 400 triangles. These are 800 to 1,100, and need about 25 draw calls for all the variants where the game now uses 9.

The skater is one model on screen, so its triangles hardly matter. A car today is about 200 triangles and there are 24; these are 300 to 700. Furniture is 80 to 450 a piece and goes into the cell batches, so what counts is how many are put on each street.
